## A note on ground truth (important finding, not a footnote)

The first version of `ground_truth.py` used pandas' `idxmin()`/`idxmax()`
for "closest game" and "biggest win." Both silently return only the
*first* matching row when there's a tie — and there IS a tie in both
cases (see above). The script didn't error, didn't warn, just quietly
reported one game as if it were the only answer.

**An LLM's answer during Phase A testing (Q7) is what caught this** — it
checked for ties where the original ground-truth script hadn't, and
found all four 1-goal games. The script has since been corrected. This
means the "ground truth" wasn't fully trustworthy on first pass; it was
only as good as the edge cases its author thought to check for, and in
this instance a language model was more careful than the reference
script it was ostensibly being tested against.
